# Privacy

This public MVP does not use accounts, logins, analytics, or a backend database.

User entries are stored only in the current browser's `localStorage`.

This means:

- Records are not uploaded by this site.
- Records do not sync across devices.
- Clearing browser data can delete records.
- Anyone using a shared computer should avoid entering private information.

Future versions with accounts, cloud sync, AI reports, or analytics will need a new privacy policy and data deletion/export controls.
