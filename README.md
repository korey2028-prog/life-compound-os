# 每日人生复利系统

本项目是一个无账号、无登录的静态公开 MVP，用来把 AI、运动营养、健身教学、阅读和恢复记录成每日操作台。

打开方式：

```text
直接打开 index.html
```

## 公开 MVP 原则

- 无账号。
- 无登录。
- 不上传用户记录。
- 记录只保存在当前浏览器 `localStorage`。
- 用户可以复制 Markdown 到自己的 Obsidian、Notion 或任意笔记软件。
- 健康与营养内容只做日常记录和运动营养决策支持，不做疾病诊断。

## 方法来源

- Naval 式人生复利：特定知识、杠杆、可复制资产、时间自由。
- 运动营养记录：睡眠、训练、热量、蔬菜、水果、坚果、蛋白质底线、断食日。
- 教练教学沉淀：客户跟进、方案更新、课堂反馈、模板和案例。
- AI 协作：Token 必须换回 prompt、SOP、网页功能、代码、卡片或案例。
- 笔记库原则：稳定规则放 prompt，大体量材料放知识库或笔记库。

## 当前 MVP

- 每日数据输入。
- 今日模式：恢复日、稳态日、推进日、冲刺日。
- 30 秒状态登记：可用时间、精力、焦虑、酸痛、食欲。
- 顶部 Apple 风视觉：`Think different.`、黑白产品感、克制工作台。
- 今日主线动作：AI、训练/营养、阅读/英文、教学/工作沉淀。
- 运动营养记录：蔬菜、水果、热量、坚果、断食日、蛋白质底线、训练和睡眠。
- 复利分计算：身体 25、教练 20、阅读 15、AI 20、恢复 10、自由 10。
- Compound Units 和明日负担。
- Naval 镜头判断。
- 自动生成复盘 Prompt。
- 自动生成 Obsidian Markdown。
- 浏览器本地保存最近记录。
